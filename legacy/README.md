# Legacy

Artefactos de las primeras iteraciones de este proyecto, antes de migrar a la
arquitectura de microservicios con Container Apps (ver README.md en la raíz).
Se conservan solo como referencia histórica de aprendizaje — no reflejan el
despliegue actual.

- `productsapi-vm-and-appservice/`: Bicep + cloud-init de cuando `ProductsApi`
  corría en una VM (IaaS), y los workflows de GitHub Actions de cuando se
  migró a App Service (PaaS), antes del salto final a Container Apps.
